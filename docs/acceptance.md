# 两项目验收

先准备两个可读取的真实项目，明确其规则。首次验收只读，不安装依赖或启动实验。

1. 从 Chief 登记项目 A/B，说明各自目录与任务验收标准。
2. 要求分别读取一份指定文件并输出短报告。核对真实工具轨迹及报告，不只看模型自述。
3. 要求汇总双方状态、证据、验收、阻碍和下一步，确认确实读取结果。
4. 从 Chief 自然语言切换到 A，确认是原项目会话，B 的控制状态不变。
5. 在 A 使用 `/resume` 后直接发送只回复标记的用户消息；确认 A 自动变为用户接手，B 不变。
6. 用 `/resume` 明确交回，用 `/home` 返回；检查命令不成为模型消息、草稿不残留。
7. 对 B 重复步骤 4–6；检查子菜单看板与后台状态一致。
8. 宿主空闲后正常重启；检查 Chief ID、项目会话、owner、任务、记忆与验收仍在。
9. 检查日志无重复派发；报告区分本轮新执行与读取旧结果。

本公开包附有状态机、控制器、结果回收、单写入者与记忆测试。UI 需在目标 DSH 上人工或浏览器验收。
发布前的本机 Web 回归通过；不能据此声称每个 Desktop/Windows 版本都通过。
