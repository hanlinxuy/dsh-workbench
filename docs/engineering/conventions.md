# 工程规范

## C-1：主线守卫必须通过

规则：提交前执行 pnpm test 和 pnpm check。守卫失败先修复，不以跳过、降级断言或忽略错误推进主线。

判据：同一提交的两项命令退出码均为 0；平台 CI 的失败必须追查原因。

违反的典型表现：本机单测绿，却发布了未生成的套装副本。

## C-2：证据分层

规则：单测、真实宿主、真实模型和 GUI 验收分别记录；缺失层级标未验证。

判据：验收报告含源提交、宿主版本、隔离 profile、实际命令与各层结果。

违反的典型表现：mock 返回值被描述为内网真实业务已通过。

## 晋升规则

同类错误第三次出现，当轮为错题条目增加 `→ C-数字`，在此写规则、可执行判据、典型违反形式，并补对应守卫。规范变更与代码一起审阅，不允许无记录的例外。
